# 🔐 Password Generator App

A simple and responsive password generator built with React. It allows users to generate strong, random passwords with customizable options like length, numbers, and special characters. The app also includes one-click copy functionality using the Clipboard API and auto-generation with React hooks.

---

## 🚀 Features
- Generate strong random passwords  
- Set password length using slider  
- Include/exclude numbers  
- Include/exclude special characters  
- One-click copy to clipboard  
- Auto-generate using `useEffect`  
- Optimized with `useCallback` and `useRef`  
- Fully responsive UI  

---

## 🛠️ Tech Stack
- React.js  
- JavaScript (ES6+)  
- Tailwind CSS  

---

## 📌 Purpose
This project is built for learning React hooks and improving frontend development skills while creating a useful real-world tool for password security.
